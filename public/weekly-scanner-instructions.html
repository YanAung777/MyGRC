Security Architect Standard Operating Procedure (SOP)

Weekly LLM Market Auto-Assessment Runbook

Continuous GRC evaluation protocol for discovering, auditing, and maintaining an enterprise-approved AI foundation model whitelist. Complies with ISO 42001 (Clauses 8.4 & 9.1), ISO 27001 (A.8.1.1), NIST AI RMF, and EU AI Act.

Frequency: Every Monday at 06:00 UTC
Responsible Role: Lead AI Security Architect / GRC Lead
Execution Script: scripts/weekly_llm_scanner.py
Target Platform: C&A Portal Model Registry

1. Objective & Regulatory Mandate

Under ISO/IEC 42001:2023 Clause 8.4 (AI System Impact Assessment) and NIST AI RMF (GOVERN 1.2), organizations deploying Artificial Intelligence must not allow unvetted foundation models into engineering pipelines without verified security, privacy, and safety provenance.

This automated continuous scanner crawls model releases, vendor terms of service, and enterprise data processing agreements (DPAs) across OpenAI, Anthropic, Google Cloud, Meta, Mistral, DeepSeek, Cohere, and open-source hubs to determine which models meet enterprise security criteria.

Approved Whitelist Threshold

Models scoring ≥85/100 with contractual Zero Data Retention (ZDR) and prompt training opt-out are promoted to Approved.

Restricted / Sovereign Caveats

Models lacking US/EU residency or public DPA (e.g. DeepSeek-R1) are flagged Restricted (approved only for isolated internal VPCs).

2. The 7-Pillar GRC Scoring Rubric

Every scanned foundation model is scored against a 100-point weighted architectural rubric:

Pillar Weight Verification Criteria Impact on Approval
1. Zero Data Retention (ZDR) 25 Pts Enterprise DPA legally guarantees prompt/output discarded immediately post-inference. Mandatory for PII / Confidential Data
2. Training Opt-Out Guarantee 20 Pts Contractual commitment that API payloads are never used to pre-train or fine-tune vendor models. Strict Prerequisite for Approved Status
3. Independent Certifications 15 Pts Verified SOC 2 Type II audit report, ISO 27001 certificate, and HIPAA BAA availability. 8 pts (SOC 2) + 7 pts (ISO 27001)
4. EU AI Act Systemic Risk Tier 15 Pts Classification: GPAI with Systemic Risk (>10^25 FLOPs compute threshold) vs Specific/Minimal Risk. Full transparency & red-teaming report required
5. Regional Data Residency 10 Pts Regional compute boundary (US only, EU sovereign cloud, or customer VPC on AWS Bedrock/GCP Vertex). Guarantees compliance with GDPR & sovereign laws
6. Jailbreak & Red-Team Robustness 10 Pts Resilience against prompt injection attacks, system prompt extraction, and OWASP LLM Top 10 vulnerabilities. Evaluation from public red-team benchmarks
7. Safety Filters & Moderation SLA 5 Pts Automated content moderation API integration and enterprise uptime SLA (≥99.9%). Assures reliable business continuity

3. Weekly Operational Runbook (Step-by-Step)

Follow these steps every Monday morning to execute the scan and update the model registry:

Step 1: Environment Preparation

Ensure Python 3.9+ is installed on your local workstation or CI/CD runner. No external dependencies are mandatory (standard library is used):

python3 --version # Must be >= 3.9

Step 2: Execute the Automated Assessment Scanner

Run the scanner to crawl market intelligence and produce the structured JSON feed:

# 1. Run scanner and output to JSON
python3 scripts/weekly_llm_scanner.py --output market-models-feed.json --verbose

Step 3: Direct API Synchronization (Option A - Automated)

If the C&A Portal server is running, the script can push the parsed models directly into the database with one flag:

python3 scripts/weekly_llm_scanner.py --upload-to-app --app-url http://localhost:3000

Step 4: Web UI Ingestion (Option B - Manual Review)

  1. Open the C&A Portal in your browser.
  2. In the sidebar, navigate to Models.
  3. Click the Import / Export JSON button in the top action toolbar.
  4. In the Import Models tab, drag & drop the generated market-models-feed.json file (or paste its content).
  5. Select Ingestion Strategy: Merge & Update (recommended to preserve existing use cases).
  6. Inspect the parsed models preview table and click Import Models.
💡 Pro-Tip for Gateway Enforcement: Once imported, use the Export Registry & Whitelist tab to download approved-llm-whitelist.json and feed it directly into your LiteLLM or Portkey API proxy to prevent engineers from making calls to unauthorized LLM endpoints.

4. Automated Scheduling (Cron & GitHub Actions)

To run this scan completely hands-free on a recurring schedule:

Linux Crontab Setup:

# Run every Monday at 06:00 UTC and upload to the C&A Portal API
0 6 * * 1 /usr/bin/python3 /opt/ca-portal/scripts/weekly_llm_scanner.py --upload-to-app --app-url https://your-portal-domain.com >> /var/log/llm-scanner.log 2>&1

GitHub Actions Workflow (.github/workflows/weekly-llm-scanner.yml):

name: Weekly LLM Market GRC Assessment
on:
schedule:
- cron: '0 6 * * 1' # Every Monday at 06:00 UTC
workflow_dispatch: # Manual trigger

jobs:
scan:
runs-on: ubuntu-latest
steps:
- name: Checkout Code
uses: actions/checkout@v4

- name: Set up Python
uses: actions/setup-python@v5
with:
python-version: '3.11'

- name: Run Market Scanner
run: |
python scripts/weekly_llm_scanner.py --output market-models-feed.json

- name: Upload Artifact
uses: actions/upload-artifact@v4
with:
name: market-models-feed
path: market-models-feed.json
